# 專案結構

← 回 [[Home]]

## 技術棧

| 項目 | 使用 |
|---|---|
| 前端框架 | Vue 3（Composition API、`<script setup>`、純 JavaScript，非 TS） |
| 建置工具 | Vite 7 + `@vitejs/plugin-vue` + `vite-svg-loader`（`.svg?component`）|
| 樣式 | Tailwind CSS 4（`@tailwindcss/postcss`）＋大量 scoped `<style>` |
| 後端服務 | Firebase：Auth／Firestore／Storage／Hosting／Functions |
| 後端函式 | Cloud Functions v2（TypeScript），獨立子專案於 `functions/` |
| PWA | 純手動（`public/manifest` 等），無 Workbox / service worker 註冊（見 [[已知問題]]）|

## 資料夾樹狀圖

```
yabuy-mvp/
├── src/
│   ├── App.vue                 # 根組件：分頁路由、選單、彈窗、Auth 監聽 → 見 [[導覽架構]]
│   ├── main.js                 # Vue app 掛載
│   ├── firebase.js             # Firebase 初始化（auth/db/storage/functions 匯出）
│   ├── style.css               # 全域樣式（Tailwind entry）
│   ├── assets/
│   │   ├── icons/*.svg         # 導覽列 / 按鈕圖示（Lucide 風格，24×24，currentColor）
│   │   └── map/AU-Map-01.jpg   # 校園地圖圖片（見 [[已知問題]] 檔案過大）
│   └── components/
│       ├── Landing.vue         # 行銷首頁 + Email/Google 登入註冊
│       ├── Onboarding.vue      # 首次使用 3 頁導覽
│       ├── List.vue            # 左側滑出選單 + 個人資料表單
│       ├── Home.vue            # 首頁：滑卡瀏覽（Tinder 式）
│       ├── Funnel.vue          # 搜尋／分類篩選（清單式）
│       ├── Book.vue            # 教科書：依學院/系所瀏覽
│       ├── Cam.vue             # 拍照上架
│       ├── User.vue            # 個人頁：我的賣場/已買/收藏、編輯資料
│       ├── Heart.vue           # 收藏列表（獨立頁，目前無導覽入口，見 [[已知問題]]）
│       ├── Mailbox.vue         # 交易信箱：買入請求／收到訂單／系統公告
│       ├── TradeModal.vue      # 發起交易的底部彈窗（時間/地點）
│       ├── Deal.vue            # 面交當下：QR 掃描互認 + 確認成交 + 評價
│       ├── MapPage.vue         # 校園地圖全螢幕頁
│       ├── Admin.vue           # 管理後台（商品巡邏/用戶/日誌/公告/指標入口）
│       ├── Indicate.vue        # 營運指標儀表板
│       ├── SendSuccessAnimation.vue  # 送出交易請求後的成功動畫
│       ├── ToastHost.vue       # 全域 toast + confirm 對話框渲染
│       ├── verify.js           # 信箱驗證狀態判定（單一事實來源）→ 見 [[驗證與權限]]
│       ├── toast.js            # toast() / confirmDialog() 狀態與 API
│       ├── modalState.js       # 「目前有幾個全螢幕彈窗開著」計數器
│       ├── Categories.js       # 商品分類清單
│       └── Subject.js          # 學院/系所資料（教科書分類用）
├── functions/
│   └── src/index.ts            # Cloud Function：addAdminRole（管理員授權）
├── public/                     # 靜態資源（PWA icon、manifest 等）
├── .claude/launch.json         # Claude Code 預覽用的 dev server 設定（本次協作新增）
├── firebase.json                # Hosting rewrite / Functions predeploy / Firestore indexes 指向
├── firestore.indexes.json      # 複合索引定義 → 見 [[資料模型]]
├── vite.config.js              # alias `@` → src、CORS headers、host:true
└── package.json
```

> 沒有 `firestore.rules` / `storage.rules` 檔案在這個 repo 裡——安全規則是直接在 Firebase Console 管理的，不受版本控制。見 [[已知問題]]。
