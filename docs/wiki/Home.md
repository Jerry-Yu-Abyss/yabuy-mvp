# YaBuy Wiki

亞洲大學校園二手交易 PWA —— Vue 3 + Firebase。這份 Wiki 統整**專案資料夾結構**與**系統功能**之間的對應關係，採 Obsidian 雙向連結（`[[筆記名稱]]`），可直接在 Obsidian 開啟 `docs/wiki/` 這個資料夾當作 vault 瀏覽。

## 導覽

- [[專案結構]] —— 資料夾樹狀圖、技術棧、各檔案定位
- [[元件目錄]] —— 每個 `.vue` / `.js` 檔案做什麼、被誰使用
- [[系統功能]] —— 依「使用者能做的事」分類，對照到實作檔案
- [[導覽架構]] —— App.vue 的分頁 / 選單 / 彈窗如何組成整個畫面
- [[資料模型]] —— Firestore 各 collection 的欄位與索引
- [[交易生命週期]] —— 一筆訂單從發起到完成/取消的狀態機
- [[新交易流程規格]] —— 🚧 簡化版交易流程草案（罐頭訊息、取消上限、安全交易、實體 QR）
- [[驗證與權限]] —— Email 驗證判定、管理員 Custom Claims
- [[部署與環境]] —— 開發、建置、部署指令與設定檔
- [[自訂網域與寄信設定]] —— `yabuy-tw.com` 綁定 Hosting／Resend SMTP，含踩過的 Cloudflare Proxy 坑
- [[已知問題]] —— 目前挖出但尚未處理的技術債

## 一句話定位

一個以**滑卡瀏覽（首頁）＋條件搜尋（搜尋）＋校園面交（QR 驗證）＋管理後台**組成的輕量交易平台，前端 Vue 3 直接讀寫 Firestore（無自建後端 API，僅一支 Cloud Function 管理員授權），Hosting 部署到 `yabuy-2026a.web.app`。
