# 元件目錄

← 回 [[Home]]　｜　資料夾總覽見 [[專案結構]]

依檔案列出職責、觸發方式、讀寫的 Firestore collection。collection 詳細欄位見 [[資料模型]]。

## 骨架 / 全域

| 檔案 | 職責 | 讀寫 collection |
|---|---|---|
| `App.vue` | 根組件：`onAuthStateChanged` 監聽、`activeTab` 分頁路由、底部 Dock 拖曳手勢、頂部導覽列、未讀角標訂閱 | `users`（讀 banned 狀態）、`orders`／`notifications`（角標計數）|
| `main.js` | 掛載 Vue app | — |
| `firebase.js` | 初始化 `initializeApp`，匯出 `auth / db / storage / functions / googleProvider` | — |
| `ToastHost.vue` | 渲染全域 toast 堆疊與 confirm 對話框，由 `toast.js` 驅動 | — |
| `toast.js` | `toast()` / `toast.success/error/warning/info()` / `confirmDialog()`：取代 `alert/confirm` 的統一 UI | — |
| `modalState.js` | `isAnyModalOpen` 計數器：任一全螢幕彈窗開啟時通知 `App.vue` 收起底部 Dock | — |

## 帳號 / 登入

| 檔案               | 職責                                                       | 讀寫 collection                                    |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------ |
| `Landing.vue`    | 未登入時的行銷首頁；Google 彈窗登入、Email 註冊/登入/忘記密碼                   | `users`（`upsertUserDoc`）                         |
| `Onboarding.vue` | 首次使用的 3 頁滑動教學（純 UI，`localStorage` 記錄看過）                  | —                                                |
| `List.vue`       | 左側滑出選單；目前唯一項目「更改個人資料」直接內嵌表單（改名字/頭像）                      | `users`（`updateDoc`）、Storage `avatars/{uid}.jpg` |
| `User.vue`       | 個人主頁：頭像/暱稱、信箱驗證橫幅、我的賣場/已買/收藏三分頁、編輯/下架商品、評價顯示、登出、進入管理後台入口 | `users` `products` `orders` `favorites`          |
| `verify.js`      | 信箱驗證狀態的單一判定邏輯，見 [[驗證與權限]]                                | `users`（`syncVerifyStatus`）                      |

## 上架 / 交易

| 檔案 | 職責 | 讀寫 collection |
|---|---|---|
| `Cam.vue` | 拍照/選圖 → 壓縮 → 上傳 Storage → 建立商品 | `products`、Storage `products/{ts}-{uid}.jpg` |
| `TradeModal.vue` | 發起交易的底部彈窗：選時間/地點、防呆（面交時段 06:00–18:00、不可買自己的商品、信箱驗證守門）| `audit_logs`（送出交易時記一筆）|
| `SendSuccessAnimation.vue` | `TradeModal` 送出成功後的動畫回饋 | — |
| `Mailbox.vue` | 交易信箱：買入請求／收到訂單兩個分頁；接受/婉拒/改提案/**買家自行取消**；系統公告區 | `orders` `notifications` |
| `Deal.vue` | 面交當下全螢幕流程：QR 產生（賣家）／掃描（買家）互相驗證身分 → 雙方就緒 → 確認成交 → 買家評價 | `orders`（`accepted→completed/failed`）`products`（成交後 `status:'sold'`）`reviews` |
| `CannedChat.vue` | 面交前的私訊底部彈窗：自由輸入＋常用短語快捷鍵、推遲面交時間的請求卡片、右上 ⚠️ 檢舉入口 | `messages` `reports` `orders`（推遲同意時改 `time`）|
| `can.js` | 私訊的訂閱／傳送、推遲請求、檢舉建立（單一事實來源，比照 `verify.js` 的寫法）| `messages` `reports` `orders` |
| `chatFilter.js` | 私訊內容偵測：聯絡資訊（含拆字、全形、逐字傳送）與騷擾用語，見 [[資料模型]]。純函式、不碰 Firestore，所以 `check:func` 可以離線直接載入來跑 C-23～C-25 | — |
| `Heart.vue` | 收藏列表獨立頁（目前無導覽入口可到達，見 [[已知問題]]；收藏功能仍可透過 `User.vue` 的「喜愛」分頁使用）| `favorites` `orders` |

## 管理後台

| 檔案 | 職責 | 讀寫 collection |
|---|---|---|
| `Admin.vue` | 6 個分頁：商品巡邏（強制下架＝呼叫 `purgeProduct` 連鎖刪除）、用戶管理（停權/授權管理員/三個平台開關）、**檢舉**（待處理數字顯示在分頁標籤上，可展開對話快照、駁回／標記已處置／停權被檢舉人）、安全與交易日誌、系統公告（發廣播）、指標入口 | `products` `users` `orders` `reviews` `notifications` `audit_logs` `reports` |
| `Indicate.vue` | 營運指標儀表板：用戶/商品/訂單/成交數 + 自訂健康度指標卡 | `products` `orders` `users`（唯讀彙總）|
| `functions/src/index.ts` | `addAdminRole` Callable Function：設定 Firebase Custom Claims（`admin` / `founder`），見 [[驗證與權限]] | `users`（鏡像 `isAdmin/isFounder` 供後台顯示）|
