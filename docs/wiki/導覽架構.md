# 導覽架構

← 回 [[Home]]　｜　各頁面職責見 [[元件目錄]]

`App.vue` 是唯一的路由中樞——**不是**用 vue-router，而是一個 `activeTab` 字串 ref 搭配 `v-else-if` 手動切換，外加獨立於分頁之外的滑出選單與彈窗層。

## 畫面層級（由外到內）

```
App.vue
├── Landing.vue          v-if="showLanding"（localStorage: yabuy_landing_seen 沒設過 → 顯示）
└── .native-app-container（登入前的行銷頁看不到這層）
    ├── Onboarding.vue           v-if="showOnboarding"（localStorage: yabuy_onboarded）
    ├── header .top-nav-bar      特定分頁會隱藏（map / mailbox / heart / admin / user / camera）
    │   ├── [list 圖示]  → showList = true          開左側選單
    │   ├── [搜尋框]     → 有輸入時自動切到 funnel 分頁
    │   ├── [map 圖示]   → activeTab = 'map'
    │   └── [信箱圖示]   → activeTab = 'mailbox'（含未讀角標）
    ├── main .main-stage（<keep-alive> 包裹，切分頁不重新掛載）
    │   └── activeTab 對應：radar│funnel│camera│book│user│heart(*)│mailbox│map│admin
    ├── footer 底部 Dock       dockVisible 計算屬性控制顯示/隱藏
    │   └── 5 個主分頁：首頁/搜尋/賣東西/教科書/我的（支援拖曳吸附手勢）
    └── List.vue（<Transition name="slide-panel">，v-if="showList"）
        └── 蓋滿整個 .native-app-container（含底部 Dock），從左滑入
```

`(*)` `heart` 分頁目前沒有任何按鈕會設定 `activeTab = 'heart'`，是不可達路由，見 [[已知問題]]。

## `activeTab` 對照表

| 值 | 組件 | 底部 Dock 可見 | 頂部導覽列可見 |
|---|---|---|---|
| `radar` | `Home.vue`（首頁滑卡）| ✅ | ✅ |
| `funnel` | `Funnel.vue`（搜尋）| ✅ | ✅ |
| `camera` | `Cam.vue`（賣東西）| ✅ | ❌（進到相機頁不顯示頂部列）|
| `book` | `Book.vue`（教科書）| ✅ | ✅ |
| `user` | `User.vue`（我的）| ✅ | ❌ |
| `heart` | `Heart.vue`（收藏，不可達）| ❌ | ❌ |
| `mailbox` | `Mailbox.vue`（信箱）| ❌ | ❌ |
| `map` | `MapPage.vue`（地圖）| ❌ | ❌ |
| `admin` | `Admin.vue`（管理後台）| ❌ | ❌ |

## 彈窗層（獨立於 `activeTab`）

這些用 `isAnyModalOpen`（[[元件目錄|modalState.js]]）計數，開啟時自動收起底部 Dock：

- `TradeModal.vue` —— 各瀏覽頁按送出鍵開啟，`registerModalOpen/Close`
- `List.vue` —— 左側選單，`position:absolute; inset:0` 蓋滿容器（比彈窗更高的 z-index，不走 `isAnyModalOpen` 計數，因為本身就是全螢幕覆蓋層）
- `Deal.vue` —— 用 `<Teleport to="body">` 掛到 body，脫離 `.native-app-container` 的桌機置中限制

## 個人資料編輯的特殊之處

`List.vue` 點「更改個人資料」**不會**切換 `activeTab`，而是在同一個滑出面板內部用 `view` ref（`'menu' | 'profile'`）切換內容。存檔後 `emit('saved')`，`App.vue` 呼叫 `triggerRef(currentUser)` 強制刷新——因為 `updateProfile()` 是直接改 Firebase 內部的 user 物件本身，Vue 的響應性系統偵測不到這種「繞過 ref setter 的物件內部修改」。細節見 [[驗證與權限]]。
